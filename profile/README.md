# 3 Leaps

**Independent open source, published under its own names.**

[3 Leaps](https://3leaps.net) is a North Carolina LLC. This GitHub organization,
[`3leaps`](https://github.com/3leaps), is the public collection of libraries,
tools, and apps that are useful beyond any one product line. Each project keeps
its own name. The org is the publisher.

This collection is not [Lanyte](https://github.com/lanytehq) (the agent
platform) and not [Fulmen](https://github.com/fulmenhq) (DX and forge libraries).

## Explore the projects

Libraries (`*prims`) are daemon-free primitives you can embed. Tools are
unsuffixed CLIs and utilities. Apps are products you run. Standards live in
their own catalogs.

### Libraries

| Project | What it does |
| --- | --- |
| [sysprims](https://github.com/3leaps/sysprims) | Process control primitives with permissive licensing, including group-aware timeouts. |
| [sysprims-pty](https://github.com/3leaps/sysprims-pty) | Owned PTY sessions with race-free process containment, built on sysprims. |
| [ipcprims](https://github.com/3leaps/ipcprims) | Framed, multiplexed local IPC over Unix sockets and Windows named pipes. |
| [waitprims](https://github.com/3leaps/waitprims) | First-match event wait without a daemon, for agent seats and services. |
| [storageprims](https://github.com/3leaps/storageprims) | Provider-neutral object-storage primitives with an implemented S3 backend. |
| [docprims](https://github.com/3leaps/docprims) | Permissively licensed text extraction from documents. |

### Tools

| Project | What it does |
| --- | --- |
| [seclusor](https://github.com/3leaps/seclusor) | Local-first secrets management with age encryption, a CLI, and library bindings. |
| [sfetch](https://github.com/3leaps/sfetch) | Verifiable downloader that checks signatures and checksums before you run anything. |
| [shellsentry](https://github.com/3leaps/shellsentry) | Static risk assessment for shell scripts you are about to trust. |
| [decernor](https://github.com/3leaps/decernor) | Local key-material hygiene and readiness checks that inspect state, not secrets. |
| [seekable-zstd](https://github.com/3leaps/seekable-zstd) | Seekable zstd for random-access reads and parallel decompression. |

### Apps

| Project | What it does |
| --- | --- |
| [gonimbus](https://github.com/3leaps/gonimbus) | High-scale cloud object storage inspection, crawl, and reflow. |
| [kitfly](https://github.com/3leaps/kitfly) | Turns a folder of writing into a small website or slide deck. |
| [mdmeld](https://github.com/3leaps/mdmeld) | Packs files into a markdown archive that humans and agents can share. |

### Standards and policies

| Project | What it does |
| --- | --- |
| [crucible](https://github.com/3leaps/crucible) | Lightweight standards baseline for coding, commits, observability, and AI-assisted work. |
| [oss-policies](https://github.com/3leaps/oss-policies) | Governing policies for 3 Leaps open-source communities. |

Install many of the CLIs from the [Homebrew tap](https://github.com/3leaps/homebrew-tap)
or the [Scoop bucket](https://github.com/3leaps/scoop-bucket).

Projects are at different stages of development. Each repository's README and
release notes describe its current capabilities, maturity, and setup. For a
hands-on starting point, see [sfetch](https://github.com/3leaps/sfetch) or
[seclusor](https://github.com/3leaps/seclusor).

## Get involved

Start with the documentation and issues in the project you want to use or
contribute to. Our [contributor guide](https://github.com/3leaps/.github/blob/main/CONTRIBUTING.md)
and [support guide](https://github.com/3leaps/.github/blob/main/SUPPORT.md)
explain where to go next. Please report vulnerabilities through our
[security policy](https://github.com/3leaps/.github/blob/main/SECURITY.md).
